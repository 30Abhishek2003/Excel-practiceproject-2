# ☕ Coffee Sales Dashboard
 ---

## 📊 Dashboard Overview
---


An interactive data analysis dashboard built to track, visualize, and analyze global coffee sales performance from 2019 through 2022. This dashboard provides key insights into revenue trends over time, geographical sales distributions, product type performance, and top customer behavior.


---


## 🔑 Key Features & Insights

---


*   **Total Sales Over Time (Line Chart):** Tracks monthly revenue cycles across individual coffee bean varieties (**Arabica**, **Excelsa**, **Liberica**, and **Robusta**) from 2019 to mid-2022.
*   **Sales By Country (Horizontal Bar Chart):** Provides geographical breakdown highlighting market dominance across the **United States**, **Ireland**, and the **United Kingdom**.
*   **Top 5 Customers (Ranked Bar Chart):** Identifies the highest-value patrons (e.g., Allis Wilmore, Brenn Dundredge) to track high-value loyalty and retention metrics.
*   **Dynamic Interactive Slicers:** Full-dashboard filtering capabilities based on:
    *   **Order Date:** Monthly timeline buttons (Jan - Dec).
    *   **Roast Type Name:** Dark, Light, Medium.
    *   **Size:** Product package sizes (0.2 kg, 0.5 kg, 1.0 kg, 2.5 kg).
    *   **Loyalty Card Status:** Yes / No member segmentation.
 

---


## 🛠️ Tech Stack & Skills Used

---


*   **Application:** Microsoft Excel / WPS Office Spreadsheet
*   **Data Modeling:** Power Query (ETL process for merging customer, product, and orders data tables)
*   **Formulas Used:** `XLOOKUP`, `INDEX/MATCH`, `IFERROR`, and Date functions for data enrichment
*   **Data Aggregation:** PivotTables & PivotCharts
*   **UI/UX Design:** Custom dashboard theme layout, conditional formatting, and synchronized slicer connections
